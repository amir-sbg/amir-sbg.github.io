FlexSplat

Flexible Feed-Forward 3D Gaussian Splatting without Point Cloud Correspondence

Amir Sabbaghziarani Hanting Ye Maria Gorlatova Yi Ding
Paper Code BMVC 2026 BibTeX

FlexSplat reconstructs object-centric scenes from uncalibrated images by jointly estimating geometry and decoding a compact, shared set of 3D Gaussian queries.

Abstract

FlexSplat is a feed-forward framework for novel view synthesis from uncalibrated, object-centric multi-view image collections. It removes the posed-input assumption of query-based Gaussian reconstructors by training a geometry transformer jointly with the Gaussian decoder. The geometry branch predicts per-image cameras and depth, while the decoder uses depth-guided Gaussian parameterization and multi-view deformable cross-attention to aggregate evidence into a single view-consistent set of primitives.

The representation uses a compact Gaussian budget that is decoupled from the input resolution and not dictated by the number of views. On ShapeNet-SRN and Google Scanned Objects, FlexSplat matches or approaches posed state-of-the-art reconstructors while requiring neither camera poses nor ground-truth depth.

Method

Correspondence-free Gaussian queries grounded in learned geometry

Joint geometry front-end

A VGGT-based branch predicts camera parameters, depth, and confidence. It remains in the gradient path, so geometry adapts to reconstruction instead of acting as a fixed preprocessing step.

Compact query budget

Gaussians are learned transformer queries rather than pixels or point-cloud correspondences. The primitive count can be set to 10K, 15K, or 20K independent of image resolution.

Cross-view consensus

Each Gaussian projects into every view and samples fused feature maps around its reference points, letting the decoder average down moderate pose and depth noise.

Results

Pose-free reconstruction with competitive fidelity

29.73 PSNR on four-view GSO
0.041 LPIPS on four-view GSO
20K Gaussians for four views
0.992s four-view end-to-end inference

Reproduce

The codebase includes Hydra configs for Objaverse-LVIS training, ShapeNet-SRN and GSO evaluation, ablations, timing, pose metrics, and custom-image reconstruction. 

conda create -n flexsplat python=3.10 -y
conda activate flexsplat
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
pip install -r requirements.txt

python -m src.main +experiment=objaverse
python -m src.main +experiment=gso checkpointing.load=$CKPT
python -m src.demo --images path/to/images --checkpoint $CKPT --export-ply

See the GitHub repository for dataset layout, full table commands, and test instructions.
